This repository has been restructured to separate frontend and backend.

Backend: ./backend
Frontend: ./frontend

Next steps:
- Install backend deps: create a virtualenv and pip install -r backend/requirements.txt
- Initialize DB: set env vars and run flask db init/migrate/upgrade (we'll provide exact commands soon)
- Install frontend deps: cd frontend && npm install
- Start frontend: npm run dev
- Start backend: python backend/run.py
